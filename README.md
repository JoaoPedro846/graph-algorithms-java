# Graph BFS in Java

A simple graph implementation in Java featuring Breadth-First Search (BFS).

## Features

- Graph representation using adjacency lists
- Adjacency matrix generation
- Directed and undirected edges
- Breadth-First Search (BFS)
- Path reconstruction between nodes
- Custom exception for nodes not found in the graph

## Technologies

- Java

## How to Run

Run the `main` method to test the graph implementation and BFS algorithm.
